# Operational Decision artwork

Owner-supplied generated artwork from `~/.local/state/isobar-week/od-art/`,
converted on 9 October 2026 with Sharp to WebP (quality 78). Original PNGs remain
outside the repository. Desk: 1600 px wide; windows: 1000 px; portraits: 480 px;
paper: 768 px; stamps: 720 px; emblem: 256 px. The complete set is under 1 MB.

Document text, decisions and readings are live HTML; artwork contains no weather
or assessment data. Window selection follows the dossier's departure METAR.
