# Aviation artwork

## tower.png

Use case: scientific-educational. Asset type: a transparent weather cloud sprite for an illustrated aviation schematic. A single towering cumulus (TCU) cloud, sharply growing tall cauliflower turrets above a compact flat cloud base, WITHOUT the spreading flat anvil of cumulonimbus. Hand-painted Studio Ghibli-inspired soft ivory gouache, cool blue-grey lower shading, delicate ink texture, charming but believable meteorology. Isolated in side elevation, plenty of transparent margin, no sky, no ground, no rain or lightning, no airplane, no text, no labels, no background. Actual transparent alpha. Crisp readable shape at small UI size. Height slightly greater than width.

Generated with the built-in image generation tool on 2026-09-27. Transparent originals are preserved. The renderer loads and prepares this bounded asset set before animation.

These are illustrative sprites. Forecast cloud bases, coverage, visibility, and CB/TCU labels come from parsed source data. The artwork does not encode cloud tops. Illustrated aircraft are standard reference markers; the optional live traffic layer uses separate ADS-B markers. Recognition facts and source links live in `Sources/aircraft.m`. The additional glider, King Air and U-2 were generated with the same built-in image tool; their full prompts follow.
